# Automation #04 — Appointment Reminder & No-Show Recovery
**Status: 🟡 Scaffolded — not yet built** · [← Master Catalog](../MASTER-CATALOG.md)

## Catalog entry
- **Problem solved:** No-shows waste chairs/bays/time. This sends SMS/email reminders, captures confirmations, and auto-rebooks no-shows.
- **Ideal customer:** Appointment-based businesses — dentists, salons/barbers, med-spas, auto repair, real estate showings.
- **Setup fee:** $500–750 · **Monthly fee:** $297
- **ROI:** A practice losing 8 no-shows/mo at ~$200 = $1,600 lost; cutting that 50% recovers ~$800/mo vs $297 — 2.5x+ plus reclaimed staff time.
- **Required integrations:** n8n, calendar (Google Calendar/Calendly/Acuity/Jobber), Twilio, Gmail, Google Sheets.
- **Estimated implementation time:** 0.5–1 day.
