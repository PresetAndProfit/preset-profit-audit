# Automation #06 — Estimate / Quote Follow-Up Sequence
**Status: 🟡 Scaffolded — not yet built** · [← Master Catalog](../MASTER-CATALOG.md)

## Catalog entry
- **Problem solved:** Quotes get sent and forgotten; most contractors never follow up past once. This runs a polite multi-touch SMS/email sequence on every open estimate until won or lost.
- **Ideal customer:** Quote-heavy trades — roofers, HVAC installs, remodelers, auto body, landscapers.
- **Setup fee:** $600–900 · **Monthly fee:** $297
- **ROI:** Closing one extra $5,000–$15,000 job/mo from follow-up alone is 20x+.
- **Required integrations:** n8n, quoting source (Jobber/ServiceTitan/Sheet/QuickBooks), Twilio, OpenAI, Gmail, Google Sheets.
- **Estimated implementation time:** 0.5–1 day.
